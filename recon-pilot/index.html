Workflow

Designed for long-running browser operations

ReconPilot runs steps in order. If a step needs confirmation, the next step waits until you approve or reject the proposed action.

1

Record context. Use Read, Click, and Input to define what the model may inspect or operate.

2

Analyze with AI. The model receives DOM snapshots, tables, screenshots, attachments, and your prompt.

3

Confirm actions. Review proposed browser actions before they execute, or enable automatic approval.

4

Sync the report. Generate a new Feishu document with the outcome, evidence, decisions, and errors.

FAQ

Questions before installing

Does ReconPilot work only on one website?

No. It can run on any normal web page. Each saved task keeps its own page URL, steps, prompts, and selectors.

Can the AI execute arbitrary JavaScript?

No. The model returns structured JSON. ReconPilot only executes safe local action types such as click, input, wait, scroll, keyboard, and download.

How does Feishu sync work?

Each completed run can create a new Feishu document and write a clean Markdown-converted report. Sync can be turned off per settings.

What if my model cannot analyze images?

ReconPilot records screenshot and image metadata. If the chosen model or gateway rejects vision input, the result should be marked as needs_review instead of inventing visual facts.
